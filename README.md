## 快速开始（选一种）

### 方式一：在线版（无需下载）

```
https://wangshiyuan-nku.github.io/cet6-practice
```

#### 安装为手机 App（推荐）

在线版支持 PWA 安装，安装后像普通 App 一样使用——独立图标、无浏览器边框、离线可用：

| 平台 | 步骤 |
|------|------|
| **iPhone** | Safari 打开网址 → 底部「分享」按钮 →「添加到主屏幕」→ 点右上角「添加」 |
| **Android** | Chrome 打开网址 → 弹出「添加到主屏幕」横幅 → 点安装；或菜单 →「添加到主屏幕」 |
| **电脑** | Chrome/Edge 地址栏右侧安装图标 →「安装」 |

安装后桌面会出现「CET-6」图标，点击即用，不依赖浏览器。

> **更新提示**：如果打开显示旧版本，iPhone 上长按 App 图标 →「删除书签」后重新添加；Android 上 Chrome 菜单 →「添加到主屏幕」重新安装即可。页面顶部标题栏显示版本号（v2.0），可确认是否为最新版。

### 方式二：下载网页版

1. 打开 https://github.com/wangshiyuan-nku/cet6-practice
2. 点绿色 **Code** 按钮 → **Download ZIP**
3. 解压到任意文件夹
4. 双击 `index.html`，浏览器自动打开

### 方式三：桌面版 (.exe)

1. 打开 https://github.com/wangshiyuan-nku/cet6-practice/releases/latest
2. 下载 `CET6_词汇练习.exe`
3. 双击运行，独立窗口打开（无需浏览器）

> **提示**：如果之前用过网页版，可以把网页版「备份进度」得到 `.json` 文件改名为 `cet6_progress.json`，放到 `.exe` 同目录下，进度自动继承。

## 界面说明

页面顶部有四个等级：

| 等级 | 词汇量 | 说明 | 平均句长 |
|------|--------|------|----------|
| 基础级 | ~2,000 词 | 高频常用词汇，日常短句 | ~26 词 |
| 进阶级 | ~2,500 词 | 中频词汇，六级核心 | ~29 词 |
| 高级 | ~3,514 词 | 低频进阶词汇，冲刺高分 | ~29 词 |
| 长阅读 | ~2,400 词 | 原版完整长句，深度阅读训练 | ~40-50 词 |

> **长阅读模式**：展示完整版长句（不截断），适合需要上下文理解的高级训练。短句版和其他三级共用同一套学习进度。

每个等级显示 10 条句子：

```
#42                              ← 词汇序号
The professor emphasized that    ← 英文句子
the key to mastering a language
lies in daily practice.

[查看翻译 / 隐藏]                 ← 点击显示中文翻译
教授强调掌握语言的关键在于日常练习  ← 对照检查

[✓ 认识]   [→ 跳过]              ← 判断是否掌握
```

### 按钮说明

| 按钮 | 功能 |
|------|------|
| **认识** | 看懂了 → 标记掌握（含交叉掌握）→ 自动补新句 |
| **跳过** | 不确定 → 移到末尾，下次出现时标注「上次未掌握」及跳过次数 |
| **随机刷新** | 换一批句子，优先推荐未掌握的词汇 |
| **学习统计** | 查看今日学习量、累计掌握率、薄弱词汇排行榜 |
| **备份进度** | 下载进度文件，用于同步到其他设备 |
| **恢复进度** | 从文件还原进度 |
| **云同步** | 即将推出：自动读写云盘文件 |
| **新手指导** | 7 步翻页教程，快速上手（欢迎→学习→等级→特性→同步→安装→就绪） |
| **深色模式** | 切换深色/浅色主题，夜间学习不刺眼 |
| **重置进度** | 清除所有记录，从头开始 |

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `K` | 认识（掌握当前句子） |
| `S` | 跳过（稍后再次出现） |
| `T` | 显示/隐藏翻译 |
| `R` | 随机刷新句子 |
| `D` | 切换深色/浅色模式 |

### 跳过追踪

被「跳过」的句子再次出现时，卡片右上角会显示「上次未掌握」标记。每跳过一次累计计数，跳过次数越多的词会在薄弱词汇排行榜中体现，帮助你识别真正的难点。

## 进度管理与同步

### 备份与恢复

学习进度通过文件备份互通，支持跨设备同步：

- **备份进度**：点击顶部按钮，下载 `.json` 文件。建议保存到 iCloud/OneDrive/Dropbox 云盘文件夹
- **恢复进度**：换设备或重装后，点击「恢复进度」选择备份文件即可

云盘文件夹会自动在电脑和手机间同步，备份文件放进去即可间接实现多设备进度互通。每次学习自动保存到浏览器，双重保障。

### 版本兼容

进度文件包含版本号，后续功能更新导致格式变化时，旧文件自动迁移升级，不会丢失数据。

> 云同步功能（自动读写云盘文件）即将推出，届时无需手动备份/恢复。

## 常见问题

**Q：进度会丢失吗？**
A：正常不会，自动保存在浏览器里。清除浏览器数据会丢失，建议定期「备份进度」。

**Q：换电脑怎么继续？**
A：旧电脑「备份进度」下载文件 → 新电脑「恢复进度」。

**Q：需要联网吗？**
A：下载版和桌面版不需要，在线版需要。

**Q：需要安装什么吗？**
A：下载版和桌面版都不需要安装任何东西。在线版有浏览器就行。

**Q：桌面版 (.exe) 报毒怎么办？**
A：这是 Python 打包的独立程序，没有病毒。如被杀毒软件拦截，添加信任即可。
